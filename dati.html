先记住：模板只负责“怎么组织”，不负责“写什么”。内容要靠精讲/框架 + 肖四/时政；不要背万能空话。

一、先审题：四看

1. 看范围：马原 / 毛中特 / 新思想 / 史纲 / 思修——决定用哪套原理库。
2. 看主体：党 / 国家 / 社会 / 青年 / 企业 / 个人——决定“谁怎么做”。
3. 看问法：为什么（原因/依据）、是什么（内涵/特征）、怎么办（措施/路径）、意义/启示/评价。
4. 看材料：圈时间、人物、文件、转折词；材料里的“提示句”往往对应原理。
动笔前 1–2 分钟：列 3–5 个点（原理关键词 + 材料关键词），再写。

二、通用四步

① 点题：一句话回应问题（“材料表明……”“我认为……”）。
② 原理/观点：先写原理、定义、关键词；不要一上来抄材料。
③ 结合材料：“材料中……体现了……”，引用材料关键词，别整段照抄。
④ 总结：意义/做法/青年担当，一句话收尾。
格式：分点 1. 2. 3.；每点尽量“原理 + 材料”；段落短、关键词清楚。

三、分科模板

马原：原理 → 方法论 → 材料 → 结论

常用：矛盾分析法、实践与认识、真理与价值、唯物史观、商品经济/剩余价值。
句式：材料中……体现了……原理。该原理认为……。这要求我们……。材料中……正是……的体现。因此……。

毛中特 / 新思想：观点 → 材料 → 意义/做法

常用：中国式现代化、高质量发展/新发展理念、人民至上、党的全面领导、全过程人民民主、依法治国、文化自信、共同富裕、生态文明、国家安全、人类命运共同体。
句式：材料表明……。这体现了……。意义在于……。做法上要……。

史纲：背景 → 过程 → 意义/启示

常用：近代国情与两大任务、辛亥革命、建党、抗战、新中国成立、改革开放、新时代。
句式：近代以来……。材料中……。历史证明……。启示我们……。

思修：观点 → 材料 → 践行

常用：人生观/人生价值、理想信念、中国精神、社会主义核心价值观、道德、法治思维/宪法。
句式：材料中……体现了……。这说明……。作为新时代青年，要……。

五、常见失分点

  • 只抄材料，不写原理 → 没有得分点。
  • 原理和材料“两张皮” → 原理后必须接“材料中……”。
  • 不分点、一大段 → 阅卷找不到关键词。
  • 原理写错/张冠李戴 → 不如不写。
  • 空话套话太多 → 没有原理关键词。
  • 答非所问：问“为什么”却只写“怎么办”。
  • 前面写太多，后面没时间 → 每题约 18–20 分钟。

六、两个示例（只看骨架）

例 1：马原 · 人工智能（分析题第1题）

审题：范围马原；问科技影响 + 真理/价值尺度。
骨架：①科学技术双重效应；②真理尺度与价值尺度；③材料：AI 便利 + 风险；④结论：制度保障、科技向善、以人为本。

例 2：史纲 · 辛亥革命（分析题第1题）

审题：范围史纲；问辛亥意义 + 中国共产党继承。
骨架：①背景：半殖民地半封建、救亡；②过程：推翻帝制、未改变社会性质；③意义：打开进步闸门、思想解放；④启示：中国共产党继承、民族复兴。
